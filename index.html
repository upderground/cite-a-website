Quick answer

How do you cite a website?

To cite a website, collect the author, publication date, page title, website name, and URL. In APA 7, use author, date, title, site, and URL. In MLA 9, use author, page title, website name, date, URL, and access date when needed.

APA 7 website format

Author. (Year, Month Day). Page title. Site Name. URL

If the author and website name are the same organization, APA usually omits the site name to avoid repeating it.

MLA 9 website format

Author. "Page Title." Website Name, Day Month Year, URL.

MLA often includes an access date when the source has no publication date or the page may change.

FAQ

Common website citation questions

Can I cite a website with no author?

Yes. In APA, the title moves into the author position. In MLA, the entry starts with the page title.

Can I edit the generated citation?

Yes. The extension and this demo both treat citation text as reviewable output, not a locked result.

Is this a replacement for Scribbr or Citation Machine?

No. This page explains the browser workflow. Use a full generator when you need many styles or a guided bibliography product.
